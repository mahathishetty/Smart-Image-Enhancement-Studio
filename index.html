03 / ABOUT THE PROJECT

Image processing you can see.

Smart Image Enhancement Studio demonstrates spatial-domain enhancement techniques in an interactive website. It uses OpenCV and NumPy for actual processing, with Flask connecting the interface to the algorithms. The core project does not require deep learning; an optional small ML extension can be added only if permitted by your instructor.
